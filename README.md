# Linux File Permissions Security Case Study

## Overview
This repository contains a security-focused case study demonstrating the use of
Linux commands to review and modify file and directory permissions. The goal of
this project is to ensure that only authorized users have access to sensitive
files and directories by applying the principle of least privilege.

## Scenario
In this case study, I worked in a simulated research environment where incorrect
file and directory permissions could expose confidential project data. I
identified files and directories with excessive permissions and used Linux
commands to remove unauthorized access and strengthen system security.

## Key Skills Demonstrated
- Linux file and directory permission management
- Use of `ls -la` to inspect permissions, including hidden files
- Use of `chmod` to modify permissions for users, groups, and others
- Interpreting Linux permission strings (rwx)
- Applying the principle of least privilege
- Security-focused system administration

## Tools and Commands Used
- `ls -la` — View detailed file and directory permissions
- `chmod` — Modify file and directory access permissions

## Project Files
- `file-permissions-linux.md` — Full case study with commands, explanations, and security rationale

## Security Concepts Applied
- Authorization and access control
- Least privilege
- Protection of sensitive research data
- Prevention of unauthorized file modification
